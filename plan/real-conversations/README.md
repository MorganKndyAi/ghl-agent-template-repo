# Real conversations

Paste 5 to 20 real text threads of a person doing this job by hand, good and bad, one file per thread:
`lead-a.md`, `lead-b.md`... Keep every message, who sent it and when.

These set the agent's voice, the exact wording of each question, and the order. The checklist and the playbook are
built from them.

Before you save one, replace the lead's name, phone, email and address with placeholders (Lead A, [PHONE]).
Keep this repo private.
